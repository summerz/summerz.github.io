함께 사는 사람들과 친한 피터씨와 친구분을 초대해 월남쌈밥을 먹기로 한 날. 미애씨가 그렇게도 키우고 싶어하는 고양이를 함께 데려오기로 했지.  

<!-- truncate -->

고양이를 본 미애씨는 고양이랑 노느라 정신 없고, 이것저것 준비를 해서 저녁을 먹었다. 진영씨가 도착을 안했는데 전화기를 가져가지 않아서 연락도 안되고;;; - 결국 식사를 모두 마친 후 도착;  
  
월남쌈밥, 예전에 먹어본 줄 알았는데 알고 보니 처음 먹어봤다. -\_- 이것저것 주섬주섬 싸먹느라 정신이 없었다. @.@

아 참, 오늘은 public holiday. 쩝, 국경일이라는 개념은 아니라고 봐야겠지? 그냥 휴일이지. Labour Day (노동절) 라는데, 모든 주에서 쉬는 게 아니라 NSW, ACT, SA만 쉰다. 나라가 커서 그런가? 같은 이유로 쉬지만 날짜가 다르다. 거참 재밌네;  
  

호주의 주  
  

|  |  |
| --- | --- |
| ACT | : Australian Capital Territory (수도인 Canberra가 여기 있다.) |
| NSW | : New South Wales (Sydney가 여기 있다.) |
| VIC | : Victoria (Melbourne이 여기 있다.) |
| QLD | : Queensland (Brisbane이 여기 있다.) |
| TAS | : Tasmania |
| SA | : South Australia |
| WA | : Western Australia |
| NT | : Northern Territory |

  

각 주별 Labour Day / Mayday  
  

|  |  |  |
| --- | --- | --- |
| Labour Day | 10월 4일 | ACT/NSW/SA |
| Labour Day | 5월 7일 | WA |
| Labour Day | 5월 14일 | VIC |
| May Day | 5월 2일 | NT |
| Labour Day | 5월 2일 | QLD |

  
※ 아마도 ACT, NSW, SA의 Labour Day는 10월 첫째주 월요일이고 WA와 VIC의 Labour Day도 마찬가지 인듯;
