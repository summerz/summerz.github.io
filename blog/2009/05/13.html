트위터 단축키 A-Z

May 13, 2009 · 7 min read
summerz

트위터는 오픈 API를 제공하기 때문에 윈도우, 맥, 아이폰 (아이팟 터치), 웹서비스 등 각종 플랫폼에서 작동하는 트위터 클라이언트가 많습니다  저만 해도 DestroyTwitter, Twittelator Pro, Tweetree 등 여러가지 클라이언트를 사용해서 트위팅을 하고 있죠.

하지만 역시 기본은 트위터 홈페이지겠지요. 트위터 홈페이지에서 사용할 수 있는 단축키를 모아봤습니다. 아래의 리스트는 모두 로그인 된 상태에서 사용할 수 있는 기능들입니다.

의외로 단축키에 대해서 잘 모르시는 분들이 적지 않은 듯 합니다. 어떤 툴 (서비스)든지 단축키가 손에 익으면 그것처럼 편한 게 없죠. :)

단축키 ALT + 0

Skip past navigation. 화면이 우측 상단의 메뉴들을 없앨 정도로 (살짝) 스크롤 되어 내려옵니다.

단축키 ALT + 1

Twitter: home. 화면 제일 위로 이동합니다.

단축키 ALT + 2

Skip to navigation. 화면의 가장 아래 쪽 영역 (footer)로 이동합니다. 트위터 카피라이트 문구와 함께 하단에 있는 메뉴 About Us 라든지 Contact 같은 메뉴를 볼 수 있죠.

단축키 ALT + 3

Jump to the sidebar. (설명으로는 사이드바로 이동한다고 하는데, 실제 코딩은 DM (Direct Message) 쪽의 Inbox, Sent 쪽과 연결되어 있고, 별다른 작동이 이루어지지 않습니다. 혹시 아시는 분 있나요?)

단축키 ALT + h

로그인한 계정의 트위터 홈 (http://twitter.com/home) 으로 이동합니다.

단축키 ALT + p

Profile 페이지 즉, 쉽게 말하자면 남들 눈에 보이는 제 트위터 페이지로 이동합니다.

(참고로 트위터는 누구 입장에서 보느냐에 따라서 리스팅되는 글들이 각각 모두 다릅니다.)

단축키 ALT + =

트위터 페이지의 우측 상단에 있는 Find People 메뉴로 이동합니다.

단축키 ALT + s

트위터 페이지의 우측 상단에 있는 Settings 메뉴로 이동합니다.

단축키 ALT + ?

트위터 페이지의 우측 상단에 있는 Help 메뉴로 이동합니다.

단축키 ALT + l

로그아웃 됩니다.

단축키 ALT + m

자신을 언급한 글 (@자신의_아이디)을 확인하는 화면으로 이동합니다.

(약어가 m 인 걸로 보아 mention 정도 되겠군요.)

단축키 ALT + d

DM (direct message)를 확인하는 화면으로 이동합니다.

(이 단축키는 대부분의 브라우저에서 주소창에 포커스를 맞추는 단축키와 중복되어서 사용이 조금 불편한 면이 있습니다.)

단축키 ALT + >

DM (direct message)를 확인하는 화면에서 DM 받을 사람을 선택하는 셀렉트박스로 이동합니다.

단축키 ALT + u

DM (direct message)를 확인하는 화면에서 글을 작성할 수 있는 textarea 영역으로 이동합니다.

단축키 ALT + i

DM (direct message) 중에서 자신이 받은 메시지를 확인하는 화면 (inbox)으로 이동합니다.

단축키 ALT + o

DM (direct message) 중에서 자신이 받은 메시지를 확인하는 화면 (sent)으로 이동합니다.

(o인 이유는 in의 반대인 out 이면서 키보드 자판이 i 바로 옆에 있기 때문인 듯 합니다.)

단축키 ALT + f

즐겨찾기 한 트윗 (favorites)을 볼 수 있는 화면으로 이동합니다.

단축키 ALT + /

검색창으로 포커스가 이동합니다.

Trending Topics 키워드 선택하기

참고로 검색창 (ALT + /)에 포커스가 놓여져 있는 상태에서 Tab키를 누르면 Trending Topics에 소개된 키워드가 선택됩니다. 다만 화면에 선택된 것이 나타나지는 않습니다. 그 상태에서 Enter키를 치면 해당 키워드가 포함된 트윗들이 검색되어 표시됩니다.

예1)

Trending Topics의 3번째 키워드를 검색하고 싶다면 ALT + / -> Tab -> Tab -> Tab -> Enter 하면 됩니다.

그리고, 키워드가 선택된 상태에서는 계속해서 Tab (다음 키워드) 과 Shift + Tab (이전 키워드) 를 통해 키워드를 이동시켜 계속해서 검색 (Enter 사용)을 할 수 있습니다.

예2)

Trending Topics의 2번째 키워드를 검색하고 싶다면 ALT + / -> Tab -> Tab -> Enter 하면 됩니다.

이 상태에서 바로 5번째 키워드를 검색하고 싶다면 현재 2번째 키워드가 선택된 상태이므로 바로 Tab -> Tab -> Tab -> Enter 하면 됩니다.

참고사항

위의 단축키 설정은 accesskey 라는 기능으로 구현이 되어 있습니다.

그런데, Firefox의 경우에는 accesskey가 윈도우에서는 ALT + Shift 로, 맥에서는 Ctrl, 유닉스에서는 Ctrl + Shift 로 정의되어 있습니다. 좀 특이하죠. 참고하세요.
